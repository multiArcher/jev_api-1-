# 统一无人艇运动约束

循迹（Kev/Jev/Julia）、静动态避障、目标追踪、绕障回线和本地仿真共用 `jev_api/tools/navigation_motion.py`。最大指令航速50节（25.7222m/s），最大加速度1.46m/s²，最大制动幅值1.75m/s²，最大转向角速度12°/s，最大角加速度4°/s²。速度上限和转向上限可以调低，不能配置为超过这些上限。

12°/s来自11节工况。按当前约定，其他航速暂用同一个上限；没有推断实测能力曲线。默认在直线加速至50节时使用下文的实测控制器响应；未覆盖工况使用能力上限预测，到达目标速度后加速度为零。它们是预测与仿真的动力边界，速度／航向控制报文仍表示目标值，实艇执行能力需要由底层控制器实现。

转向从当前角速度开始，经过有限角加速度加速、必要时匀速、再减速到目标航向；改变指令方向不会瞬间反转角速度。零速指令按制动能力停车，同时平滑消除已有角速度，不新增转向。原来的0.5秒变速／转向参数只保留旧接口兼容，已不决定预测响应时间。

实时态势没有直接的角速度报文字段。服务按本地接收间隔和相邻航向估算角速度（支持跨0度）；首次或过期观测按零初始角速度估算。整数度航向和接收时序会带来误差，不等同于直接的角速度测量。本地闭环仿真显式保留角速度状态。

Kev每周期的16个航向候选仍表示目标航向：默认1秒偏差区间±12°，0.2秒±2.4°；不表示本周期已完成对应转角。从零角速度开始，前1秒最多旋转2°，前0.2秒最多旋转0.08°。存在动态碰撞风险时，Kev额外考虑持续转弯的较远目标航向（最多偏转90°），每项仍通过完整物理轨迹和静态检查；独立动态规划器也可以规划预测窗口内更大的目标转角。它们都不突破实际角速度和角加速度上限。

航点减速提前量采用物理制动距离和转向加减速时间。静动态避障在校准工况同时检查实测响应与可能更快的能力上限响应，覆盖完整变速、转向轨迹和后续制动尾段；追踪距离及回线候选使用相同的运动模型。提示词明确要求提前制动、避免反复换向，不再声称0.5秒完成任意变速或转向。

## 50节目标的实测加速响应

用户提供的 `0-50KN.csv` 来自一次“下发50节目标速度、由底层控制器完成加速”的试验，并非最大油门试验。因此它用于名义响应校准，**不改写最大加速度能力曲线**。原始文件的SHA-256、采样数和提取方法保存在 `jev_api/tools/data/acceleration_0_50kn.json`，不包含位置或平台信息。

默认配置 `ACCELERATION_RESPONSE=measured_0_50kn`，也可通过 `--acceleration-response measured_0_50kn` 或 Python 策略构造参数 `acceleration_response=` 设置。仅在目标为50节、存在已知航向、目标航向与当前航向一致且初始角速度为零的加速预测中使用。考虑两位小数控制量化，目标速度允许±0.005m/s、航向允许±0.005度的编码误差。目标50节本身仍受最大速度硬限约束；其他目标、转弯、未知启动方向和制动均使用原能力边界。

数据按第二个“时间”字段恢复10Hz采样，以每0.5节首次达到的时刻提取单调速度—时间曲线，消除短时速度回落。低于首条记录0.2278节的部分按首个区间斜率外推至零；从当前速度进入曲线，不因重复发同一目标而重新启动。该近似忽略控制器历史状态，仅代表本次工况的名义响应。从首条记录速度起，35.52秒达到50节；全记录速度误差RMSE约0.136节，最大约0.516节。现有能力曲线和1.46m/s²硬上限始终生效。

静态和动态安全检查对校准工况同时评估名义响应和能力上限响应；动态检查使用同一主预测时段并逐目标合并最差结果。防止把实测加速较慢误当作“不会更快”。这两个响应假设仍不是所有可能实际轨迹的安全包络。设置 `ACCELERATION_RESPONSE=bounded` 可关闭实测响应，恢复纯能力上限预测。低层 `predict_ground_motion` 直接调用默认仍为 `bounded`；各功能通过统一配置显式选择实测模式。

重建校准文件：

```bash
python -m server.experiments.calibrate_acceleration /path/to/0-50KN.csv \
  --output jev_api/tools/data/acceleration_0_50kn.json
```

小幅变速、真实制动和转弯响应需要相应实测数据，不能从本次直线加速记录推出。

## 航速曲线接口

服务支持 `--motion-curves-file PATH` 或环境变量 `MOTION_CURVES_FILE`；文件内容为JSON。Python构造策略可用 `motion_curves={...}`；独立动态规划配置 `AvoidanceConfig` 也接受同名字段。

```json
{
  "acceleration_curve": [[0.0, 1.46]],
  "deceleration_curve": [[0.0, 1.75]],
  "turn_rate_curve": [[5.6588888889, 12.0]]
}
```

以上单点仅重现当前固定上限，并非新增标定数据。各点为 `[航速m/s, 正值能力上限]`，航速必须非负、严格递增；加速度、制动和角速度上限分别不能超过1.46、1.75和12。相邻点线性插值，区间外取端点；空曲线用固定上限。纵向积分随当前航速查询曲线。转向预测保守使用本次变速区间内的最低角速度上限，制动提前量使用曲线最低制动能力。角加速度默认4°/s²。

提供实测点后替换曲线文件即可。容器部署时路径须在容器内可读，可在自建镜像中复制文件或通过挂载提供；代码和环境配置变更后需要重建镜像／重启决策服务。仅修改源文件不会改变已运行服务。历史实验目录保留旧参数和旧结果，不能作为新参数的验收证据。

## 大航向偏差时的循迹对准

Kev 在无实际动态风险的环境循迹时，当前航向与实际引导目标的方位偏差超过30°，进入低速对准：目标航速上限10节，沿用障碍绕行时更低的安全速度。偏差回到15°以内才退出，避免在阈值附近反复切换。任务或航点变更会重置对准状态。

对准阶段提供16个持续航向目标，包含引导目标的准确方位，以10秒物理预测评估实际航向和移动后的目标方位。航向命令可超过单周期12°，实际运动仍受12°/s角速度和4°/s²角加速度约束。每个控制周期重新决策，10秒是评价时段而非开环保持时长。存在通过静态避碰、制动检查且能改善航向至少2°的候选时，过滤无效直行和微调；没有这样的安全候选时保留原安全集合。提示词要求优先改善预测航向误差，避免用极小的单步距离收益代替转向。

移动或运动状态不确定目标的存在本身不关闭对准。进入对准前，按动态动作检查窗口（默认10秒，仍包含必要的响应及制动尾段）检查低速持续转向候选、正常引导指令及当前速度航向的延续；任何探测动作存在风险或相关不确定性时，保留原动态规划器的速度空间、持续转向、避让侧和回线逻辑。探测动作全部安全时才启用低速对准，最终候选和发送前指令仍通过动态守卫。60秒预警本身不抑制对准。此门槛是保守的动作检查，不代表已完成全局动力学可达性证明。物理上限不变，也未用直线加速数据推导新的转向能力。

每轮新增 `Kev guidance` 日志，记录任务ID、从0起的 `target_index`、从1起的 `target_waypoint`、本艇经纬度/实际速度/航向、目标方位/航向偏差/距离、对准开关及原因、抑制对准的目标ID，以及动态目标的ID/速度(m/s)/航向/接收年龄。`Kev decision` 记录模型选项、候选数量、目标速度/航向、动态状态/风险ID及推理耗时；原 `sent control 0x0662` 继续记录实际发送内容。决策记录的 `alignment_gate` 保留对准门槛结果，便于与日志对照。


同向慢目标绕行时，接近航点采用基于剩余制动距离的计划速度参考。`routeSpeed` 是软参考，100米到点圈不作为硬限速区；超过计划速度不剔除候选或终止任务。全局能力上限和避碰检查继续强制执行。具体适用范围见[动态避障说明](navigation/dynamic_avoidance/README.md)。


动态避碰增加控制器响应检查：保留配置的物理制动上限，同时校核暂定0.9m/s²较慢制动及默认2秒控制延迟。对向有效会遇按TCPA/DCPA分预备调速与实际转向阶段，不单凭远期预警开始转向。该控制器响应是假设性规划预留，尚未完成本轮联调标定；具体触发条件见动态避障说明。
