直线加速至50节默认使用实测控制器响应，安全检查兼顾能力上限；适用范围与开关见[实测响应说明](../../MOTION_LIMITS.md)。

当前物理约束及曲线接口见[统一运动参数](../../MOTION_LIMITS.md)。历史验证结果不自动代表当前参数。

# 独立动态避障

**已接入 Kev，静态与动态分别判断；Jev/Julia 不接入。** 核心模块仍可独立调用，不读实时态势、不发控制指令，不依赖模型服务。调用方为每个任务创建一个 `DynamicAvoidancePlanner`，串行调用，切换任务时创建新实例或执行 `reset()`。Kev 接入集中在本目录的 `kev.py`，动态预测不接收静态目标。

## 使用

从仓库根目录设置 `PYTHONPATH=jev_api:.`。内部速度全部使用米／秒，位置使用固定原点的东／北米坐标；航向从正北顺时针，0°为北、90°为东。

```python
from server.navigation.dynamic_avoidance import (
    Action, DynamicAvoidancePlanner, Target, Vessel,
)

planner = DynamicAvoidancePlanner()
result = planner.plan(
    Vessel(position_m=(0, 0), speed_mps=10, course_deg=0),
    [Target(target_id=20, position_m=(0, 600), speed_mps=10, course_deg=180)],
    Action(speed_mps=10, course_deg=0),
)
print(result.status, result.action, result.assessment)
```

也可以调用 `scene_from_situation(records, origin_lon_lat=(120, 30), speed_unit='knots', own_id=1010)` 转换协议态势，返回 `(Vessel, tuple[Target, ...])`。`speed_unit` 必须显式指定为 `knots` 或 `mps`。输入不会被修改；本艇必须具有有效位置、速度、航向和不超过5秒的接收年龄。相同编号采用最后一条记录，非法编号报错。使用本地 `_received_age_s`，不使用源协议时间戳；未提供年龄按当前快照处理，调用方必须确保这一假设成立。原点必须在同一任务中保持不变。

目标的 `position_m`、`speed_mps`、`course_deg` 可为 `None`，表示未知，不能自行用0填充。静止目标允许省略航向。直接构造对象时非法数值报错；协议转换时目标非法字段转为未知，本艇非法字段报错。模块不维护目标历史，调用方每次须提供完整已知目标快照，不能把暂时未探测到的目标直接从输入删除。

## 结果含义

| 状态 | 含义 |
| --- | --- |
| `clear` | 期望动作通过预测检查，原样返回 |
| `avoiding` | 期望动作存在风险，返回检查通过的替代动作 |
| `blocked` | 没有安全候选，`action=None` |
| `insufficient_data` | 缺失／过期目标的保守可达范围影响规划，无法确认安全，`action=None` |

`assessment.risks` 给出各有效目标的预测最小净空、最近会遇距离和时间（包括制动尾段）；`threat_ids` 为期望动作涉及的危险或不确定目标。避让成功时 `assessment` 对应返回动作；失败时对应期望动作。`uncertain_target_ids` 和 `diagnostics` 说明数据不足原因。没有有效目标时最小净空为 `None`。

失败结果中的 `emergency_action` 是经过评估的应急建议，**不是安全指令**；其完整检查结果在 `emergency_assessment` 中。它按不确定目标数量较少、最小净空较大的顺序选择。模块不会把零速直接当作安全，也不自动决定是否执行不安全建议。

## 默认预测与策略

- Kev 使用 `warning_horizon_s=60` 预警窗口和 `action_horizon_s=10` 动作窗口，积分步长0.2秒、加速1.46m/s²、减速1.75m/s²、最大转向12°/s、角加速度4°/s²。`horizon_s=60` 保留为独立预测／独立规划调用的默认长度；Kev 的动作筛选以新的动作窗口为准。输入应使用实际艇的能力配置。
- 本艇复用现有运动预测工具，保持候选指令至预测末尾，再追加具有真实时间长度的制动尾段。主预测长度至少覆盖速度转换和转向时间。
- 目标按恒速、恒航向推进，首先补偿接收年龄；独立调用可传入静止目标，Kev 接入仅传运动或信息不完整的目标，静态目标交给原静态模块。同一时间区间内检查双方相对运动线段，不以空间轨迹相交替代同时会遇。
- 基础安全中心距离为 `80 + hypot(11.6, 3.4)/2 ≈ 86.04m`，已包含本艇尺寸，不再次叠加艇体红圈。另加 `safety_margin_m`，以及 `uncertainty_mps × (接收年龄 + 预测时间)`，默认不确定性增长速度0.5m/s。净空超过0.5米才通过检查。
- 目标数据超过5秒或运动字段缺失时，用最后位置和默认30m/s的未知目标速度上界形成保守可达圆；若已报告速度更大，采用更大的值。没有位置时始终视为相关。只有可达范围完全不影响候选轨迹，才允许继续规划并保留诊断。此上界是环境假设，可按实际目标速度范围调整。
- 危险时以当前航向为中心，默认每15°生成候选，单周期航向命令偏差上限为 `max_turn_rate_deg_s × planning_interval_s`（默认12°）。有动态碰撞风险时，Kev扩展到最多偏转90°的持续转弯目标，逐项检查完整物理轨迹；实际运动受角速度及角加速度限制。独立规划器可以请求预测窗口内更大的目标转角，轨迹仍受同一物理约束。速度候选含期望速度的100%、75%、50%、25%、本艇当前速度与期望速度的较小值及零速，不主动加速到期望速度以上。
- 筛除危险候选后优先右转，其次直行减速，再次左转；同类优先靠近期望航向，再减少速度变化。上一次避让方向在偏差相差不超过15°时优先保持。期望动作重新安全时恢复原动作并清除方向记忆。

这些结果只适用于输入态势、配置的运动模型和预测范围。第一版不判断完整海上会遇规则，不预测目标意图、加速度或转弯，不包含真实侧滑、风流和感知误差模型。独立模块不会绕过现有静态规划或控制守卫。

## 当前接入状态

静态规划、直航接近、转向触发、半速规则和原静态安全检查保持原实现。有效静态目标（速度绝对值不超过0.1节，随静态阈值配置）只进入静态模块；运动及不完整目标进入动态预测。目标重新报告静止或运动时更新分类，不能重复计入两套检查。协议态势存储保留完整已知目标快照及接收年龄；运动目标过期不直接消失，而按保守可达范围判断。

Kev 先生成原静态候选，再逐一做动态检查。没有正在进行的超越时，全部通过便保留原候选和提示词；动态风险影响原期望动作时，允许恢复原转向范围中的其他方向并增加低速／零速候选。新增候选全部重新通过原静态轨迹与制动检查，不把静态目标混入动态60秒预测，也不修改静态引导点。近处静态绕行上限为25节时，动态动作同样不超过25节；只有动态目标时不固定减半，安全时保持原速度。普通避让风险解除后恢复原静态候选流程；已开始的同向超越会持续检查相对进展，直到目标落到艇后方，再恢复回线。

60秒窗口现在仅评估原期望动作的远期风险，记录 `Kev dynamic early warning` 和 `last_decision.dynamic_warning`；预警不进入模型提示词，不剔除候选、不暂停航点进展，也不拦截控制指令。10秒窗口用于 `needs_avoidance`、候选筛选和发送前复核，两处采用相同设置，避免规划放行后被长窗口守卫拦停。进入短窗口风险后才调整动作；长窗口预警解除时更新日志。

动作窗口不是硬性的“碰撞前10秒”：主预测至少覆盖完整变速及转向过程，之后还追加完整制动尾段。例如50节保持航速时，10秒主预测之后仍有约14.7秒制动尾段；安全检查可能据此更早调整。窗口参数必须为有限正数，且动作窗口不得大于预警窗口。

候选通过统一的物理加减速、有限角加速度预测；按控制报文速度单位的两位小数量化后检查。动态避让优先右转并保持相近的既有避让方向，右侧被静态安全检查否决时可选择左侧。仅在存在动态风险时缩减或扩展原模型选项，最多16项，`turn_deg` 保持末字段。模型可见 `dynamic_avoidance` 为简短状态，完整风险详情保留在 `last_decision`。

通过 `KevPolicy(dynamic_config=AvoidanceConfig(...))` 或工厂参数 `kev_dynamic_config` 配置动态预测；默认几何尺寸继承静态设置，但配置对象独立。动态转向能力和控制周期沿用当前 Kev 参数。无共同安全动作时不请求模型，返回零速等待；等待或主动让行不累计航点无进展失败，态势恢复后继续，新任务重置动态状态。

```python
config = AvoidanceConfig(warning_horizon_s=60., action_horizon_s=10.)
# KevPolicy(dynamic_config=config) 或 create_policy(kev_dynamic_config=config)
```

发送前原 `validate_control` 继续只做静态检查，新增 `validate_dynamic_control` 独立复核最新运动目标。正速指令保留静态守卫；新指令、续发旧指令和零速指令均做动态检查。风险分别记录 `static obstacle control veto`、`dynamic obstacle control veto`；动态拦截后如果零速仍不安全，另记 `dynamic obstacle zero-speed risk`。**零速不是安全保证**，显式停止与任务结束不会根据动态建议自行恢复移动。

## 同向慢目标统一绕障（Kev）

不再维护独立超越阶段。同向（与原航段夹角不超过30°）、比巡航速度慢至少0.5m/s、信息新鲜的近处目标，通过 `server/policies/moving_obstacles.py` 生成当前位置及未来10、20秒的占用圆，接入既有几何绕障引导。实际安全检查始终使用全部动态目标的实时位置、速度和不确定性预测，不将目标冻结为静态物体。

引导路径每次收到态势后更新，目标完全落到艇后方安全距离之外后释放绕行并回线。没有可确认安全的动作仍会减速或等待。移动目标绕行不套用静态绕行减半航速；已建立侧向间距时，按剩余制动距离安排接近航点的计划速度参考。`detour_approach` 表示该速度预算。全局动力学与避碰约束保持生效；计划航速不是到点硬限速。

`state.static_avoidance.moving_target_ids` 标出参与几何规划的移动目标，`static_path_xy_m` 保存绕行路线，`dynamic_avoidance` 保存动态安全检查；不再输出旧 `overtaking` 阶段。`Kev guidance.dynamic_targets` 给出实际目标位置和距离。

### 移动走廊的回线门限

回线前检查同向目标的纵向领先距离，预留完整回线的转向建立时间、侧向合并时间、两控制周期及相对追近量。几何引导点可见不再单独作为回线依据；未满足门限时继续在当前安全侧前进，禁止候选指令向目标侧切入。侧向间距不足时先持续向外建立余量，不能提前拉平航向。

附近移动目标场景按0.9m/s²暂定控制器制动响应计算航点接近预留。该值依据本次日志约0.98m/s²的减速表现留余量，不是已标定能力曲线，也不修改1.75m/s²物理减速度上限。回线前参考计划航速及制动预留安排调速。超过计划航速仅记录为提示，不因进入100米到点圈而强制剔除候选；已访问航点圈不再额外限制离圈加速。移动走廊暂时无可行动作时等待态势更新，不直接作为永久静态故障终止任务。

决策状态的 `moving_rejoin_guard` 记录阻挡目标、实际领先距离、要求领先距离、横向间距及回线预留时间。最终修改按用户要求停止本地验证，需在后续联调中确认。

### 航点计划速度

`routeSpeed` 作为计划速度参考。接近航点时依据剩余距离连续计算调速参考，并将准确参考速度加入候选，避免仅依赖10节分档跳变。`planned_speed_excess`、`planned_braking_warning` 是调速提示，不参与安全候选剔除。100米圈只用于到点判定，不是硬限速区。物理50节上限及静动态轨迹、碰撞制动尾段检查继续强制执行。

### 碰撞判定与任务终止

控制循环在更新到点进度、采纳模型动作及正常完成判定之前，检查当前实测中心距离。静态目标进入 `obstacle_config.collision_radius_m`，或新鲜动态目标进入 `dynamic_config.safe_distance_m`（默认均约86.04米）时，抛出 `CollisionDetected`，错误码 `COLLISION_DETECTED`。服务下发零速指令，上报任务失败 `status=3`，结束当前任务；服务进程继续接收后续任务。静止本艇仍检测动态目标靠近。

这里将进入配置避碰范围作为碰撞任务失败判据，并不声称确认船体发生物理接触。动态目标过期位置不会用作实际碰撞证据，仍交给预测风险守卫处理。预测轨迹负净空仍是避让/停车等待条件，不单独触发碰撞任务终止。失败描述会明确零速只是已下发，尚未确认实际停车。

### 对向接近的提前预判与分阶段介入

Kev 对新鲜、航向与本艇相差至少150°且正在接近的目标计算最近会遇时间（TCPA）、最近会遇距离（DCPA）及预计进入安全范围的时间。只有预测轨迹可能进入含余量的安全范围，且会遇落在自适应预判窗口内，才激活提前避让；远处目标和安全错开的目标不会仅因距离近或60秒预警改变航向。

预判窗口按本艇当前/期望航速、保守制动时间、建立侧向间距的转向时间、控制延迟和5秒余量计算，至少10秒、至多60秒。分为 `prepare` 和 `maneuver`：较远风险先保留原计划航向，在安全候选内选择较高的可用速度；只有进入安全范围的剩余时间接近转向预算，才正常进入转向阶段。若原航向已无安全候选，可提前进入转向，记录 `no_safe_route_heading_action`，安全约束优先。已经转向后保留窗口，直到目标在原行进方向上落后安全距离再加20米，避免反复回线。

动态轨迹同时检查原配置制动模型和暂定0.9m/s²控制器制动响应，并加入至少两个控制周期的指令延迟（默认2秒）。1.75m/s²物理上限未改变；0.9是根据现有日志采取的保守规划假设，并非完整制动标定。模型筛选、对准门控及发送前动态检查共同使用这些假设。

发送前若原指令被最新态势否决，正常行驶中尝试有限的持续转向与速度组合，通过静动态检查且再次通过最新态势检查后才发送 `dynamic_escape`。远期预备阶段优先尝试原航向的适度减速；搜索最多19个组合，并受四分之一控制周期、上限0.25秒的开始检查预算限制；单次轨迹检查本身为同步计算。没有安全替代动作时发送零速；若零速预测仍有风险，则进入 `emergency` 状态并明确报告，不能把它当成安全停车。主动停止、任务完成及碰撞终止不会改发避让动作。

`Kev encounter` 日志和模型状态 `dynamic_avoidance.early_avoidance` 给出阶段、目标、实际生效窗口、会遇时间与距离、转向触发时间及提前介入原因。本次修改按用户要求未运行本地测试或仿真。
