# Kev 绕障后回归航线

`route_rejoin.py` 负责独立的米制回线几何和任务状态，不调用模型、不做目标运动预测，也不发送控制。Kev 默认启用；Jev/Julia 不接入。

任务第一次有效观测的位置固定为首段起点，之后以相邻两个任务航点定义航段。实际静态绕行或动态避让（包括动态等待）会记录回线需求；远处静态直航接近、60秒动态预警不触发。新任务创建独立状态。触发后，同一任务后续航段也继续沿线引导。

引导优先级为静态绕行、回线、原航点。绕障结束后，不能因为已可直达航点就跳过回线。将本艇投影到原航段，向前取汇入点；前视距离为 `max(30米, 当前速度×8秒, |横向偏差|/tan(30°))`，不越过航段终点。首选连线受阻时以30米步长向前检查；找不到安全连线时继续原有安全导航，保留回线需求。重复航点回退到原导航，由原航点完成判定处理。临近终点可直接汇入终点，不额外折返。

静态连线检查复用原有避碰半径及路径余量。所有回线候选还要经过原静态运动／制动检查和独立动态检查，控制发送前继续复核最新态势。动态风险再次出现时可以暂时离线避让。回线不额外固定半速，仍遵守正常速度阶段和既有避障约束。

横向偏差≤10米且航段方向误差≤5度，连续3轮记为 `following`；此前为 `rejoining`。回线时在原转向范围内补入精确的航线方向和汇入方向，保留直行及16个航向采样总数，避免均匀采样漏掉航线方向造成持续偏航。`rejoining` 优先保留朝安全汇入点误差最小的动作；进入 `following` 后，优先采用预测仍在上述容差内、最贴近航线方向的安全动作，减少降速时追逐微小横向偏差引起的摆动。动态风险仍可扩展方向。重新偏离时恢复回线。静态绕行时记录 `avoiding`，无安全汇入连线时记录 `waiting`。决策 `state.route_rejoin` 记录模式、原航段、引导点、横向偏差和沿程进度；临时引导点不算任务航点。

回线进度监控使用固定航段标识和“剩余沿程距离＋横向偏差”，不会因引导点移动而反复重置。持续静止也会触发原有恢复／失败流程；动态让行或等待仍暂停累计无进展。原100米航点到达、终点停车和显式停止流程保持不变。

## 配置与调用

```python
from server.navigation.route_rejoin import RouteRejoinConfig
from server.policies.factory import create_policy

policy = create_policy(
    backend='kev',
    kev_route_rejoin_config=RouteRejoinConfig(
        enabled=True,
        min_lookahead_m=30., lookahead_s=8., merge_angle_deg=30.,
        cross_track_tolerance_m=10., heading_tolerance_deg=5., stable_cycles=3,
    ),
)
```

直接构造 `KevPolicy` 使用 `route_rejoin_config=`；设置 `enabled=False` 可恢复原来的绕障后直达航点行为。这是独立 Python 配置，目前不新增命令行或报文字段。模块也可独立实例化：`RouteRejoin(start_xy_m, config)`，实际避让时调用 `activate()`，每轮调用 `guide(geometry, speed_mps, course_deg, segment_clear, avoiding=...)`。坐标为固定东／北米制，速度为米／秒，航向为北起顺时针。

## 验证

```bash
PYTHONPATH=jev_api:. python3 -m unittest discover -s server/tests -q
PYTHONPATH=jev_api:. python3 -m server.experiments.route_rejoin --mock --output /tmp/kev-route-rejoin
# 去掉 --mock 调用本机 Kev；不发送真实控制报文
```

闭环覆盖静态、动态、混合场景及统一物理加减速和有限角加速度模型（旧配置响应选项保留兼容），输出双方轨迹、汇入时间、横向偏差、航向误差、规划状态和独立0.02秒积分得到的实际最小净空。推理期间暂停仿真时间。容差针对当前预测与离散控制近似，不能保证实际轨迹与几何直线完全重合；尚未加入风流、侧滑和真实执行器标定。

2026-10-27 本地验证：`server/tests` 共191项通过；6组离线和6组真实本机 Kev 闭环全部完成航段。真实模型两种速度响应的汇总如下，横向偏差取末20秒最大值，净空取独立积分的全程最小值：

| 场景 | 回线耗时 | 末段最大横向偏差 | 最小净空 |
| --- | --- | --- | --- |
| 静态 | 22–25秒 | 6.89米 | 静态10.03米 |
| 动态 | 33–35秒 | 7.51米 | 动态12.30米 |
| 混合 | 25–30秒 | 7.12米 | 静态10.00米、动态18.04米 |

六组真实闭环末20秒的最大航段方向误差均为0度。上述结果对应固定测试场景，不代表实艇验证或其他态势下的安全保证。
