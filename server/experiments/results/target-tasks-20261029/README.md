# 目标追踪本地仿真，2026-10-29

使用当前 `KevPolicy`、实际本地 Kev HTTP 模型、现有静态/动态候选安全检查和独立 0.02 秒运动积分。未连接 UDP 仿真端，未修改生产追踪逻辑。场景无其他障碍物，追踪目标仍参与避碰检查。

这是合成场景，不是现场日志复现。初始目标位置 (0,0)m，本艇 (-300,-80)m；双方初速10节、航向90°。指令执行延迟2秒，决策周期2秒；HTTP推理期间仿真时间暂停。无进展计时使用仿真时钟。目标以现有运动约束加速至指定速度；30节场景在90秒后由90°转向120°，50节场景持续直线。

最大航速50节，最大加速1.46m/s²、制动1.75m/s²，最大转速12°/s、角加速4°/s²；具体加速响应和其他参数见各场景 configuration.json。目标航线运动由测试脚本生成，不验证目标自身的航线决策服务或任务报文往返。

伴随区域为目标后方140–160m、右舷70–90m，syncHeading=1；跟随距离为150–200m。除第一组外 maxSpeed=0，使用本艇50节上限。

| 场景 | 结果 |
|---|---|
| 伴随，maxSpeed=20.58节，目标50节 | 未进入区域；触发 TargetTaskUnreachable 后停车。包含停车过程的记录总长68秒。 |
| 伴随，maxSpeed=0，目标50节 | 本艇能达到50节，但无法追回初始距离；触发同一超时后停车。包含停车过程的记录总长78秒。 |
| 伴随，maxSpeed=0，目标30节 | 36秒首次进入区域；运行至160秒，无零速指令。位置仍有波动，结束时横向超出区域13.13m，不能视为稳定保持通过。 |
| 跟随，maxSpeed=0，目标30节 | 34秒首次进入距离范围；运行至160秒，无零速指令。结束距离216.81m，超出上限16.81m，不能视为稳定保持通过。 |

所有场景的密集积分最小距离均大于158m，未进入约86.04m避碰范围。稳定性结果仅针对这些参数、起始条件和本次模型选择，不能推广为现场保障。
