# 接近P2时低速并排修正

根因：原航点接近区按最大巡航速度统一提前降为10节，覆盖了尚在圈外且已建立侧向间距的超越；与9.6节目标几乎同速，导致并排。宽侧向容差和低相对进展候选还会导致左右微调。

修改：已建立侧距的超越在圈外按剩余距离和制动能力计算速度预算，保留两周期反应距离与进圈转向余量；每个候选额外检查两周期保持加完整制动轨迹，逐个核对所有任务航点圈内速度。超越阶段优先收敛到侧向参考，再选最佳安全相对进展90%内的动作，减少横向外漂漏点。全局物理上限、圈内限速及已访问点限速保持。

按16:36:15已记录的本艇位置、27.7节、162°及4001/4003位置速度，重建在P1-P2段的局部状态。初始角速度假设0、缺失的静态目标未补造；目标按当前速度航向延续，世界在真实本地Kev推理期间暂停。这不是完整UDP现场回放。对照关闭本次速度预算并使用前版超越筛选；新版开启本次修正。
