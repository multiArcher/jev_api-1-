# 静态障碍物规避实现与验证

## 已实现

- 控制任务仍只由绑定船舶ID接管，控制工作线程接收全部目标快照；本地默认绑定1010艇。
- 以本艇ID排除自身，其他速度绝对值不超过0.1节的目标按静态物体处理，包括未知类型10及其他静止艇。已知静态位置在停止探测后保留，使用本地接收年龄区分时效，不用存在111秒偏移的源端时钟计算缓存年龄。
- 障碍物禁入半径80米，艇体11.6×3.4米，外接圆半径约6.04米，艇体中心有效避碰半径约86.04米；配置可通过命令行、环境变量覆盖。
- 内部首航点米制坐标中，用带10米跟踪余量的可见路径生成绕行引导点。已选路径保持到可安全直达更远点时再推进，直达原目标恢复后退出绕行；Kev继续选择具体速度和方向。
- 候选安全检查覆盖整段预测轨迹以及预测末端后的制动路径，同时检查当前模拟变速响应和1.46m/s²加速、1.75m/s²减速边界。至少预测4秒，最长覆盖变速过程；危险候选不交给模型。绝对转角字段 `turn_deg` 保持在候选末尾。
- 实际发送前按最新态势复核新指令及续发指令。推理期间新增障碍物使原指令不安全时暂发零速；本艇已处于碰撞范围时不计为安全到达，返回 `STATIC_OBSTACLE_BLOCKED`。
- 原任务到达半径始终100米，临时引导点不计为任务航点。航点中心被占据时在原到达圈内寻找安全通过位置；无可用位置、路径或候选时停车并报告受阻。

123项自动测试通过，见 `tests.log`。覆盖原导航、控制周期、任务接管、静态几何绕行、目标停止探测后保留、未知类型、艇体包络、碰撞线段与制动路径、航点被占据、初始碰撞，以及推理期间新检测导致控制被拦截。

任务二第一次运行在第2352步请求原18028推理服务超时，原服务随后连模型列表接口也无响应；进程仍存活，原因尚未确定，不能归因于避障碰撞。测试停车后，使用另一个18029本地推理实例，从最终零速位置、29个已完成航点继续剩余路线。`resume_task_two.py` 保存恢复步骤，原航点列表不变；任务标识追加测试后缀，策略历史从停车状态重新建立。

因此任务二的45个航点是分段覆盖，不能称为一次连续全程通过。续测第825步重穿已访问的第42个航点圈时发生一次50节峰值超速（限速约10.289节），当时没有进入静态避障模式。速度阶段在进入旧圈后才从巡航切到减速，属于此前已知的旧航点圈提前限速问题；本次未扩大静态避障范围去修改这一逻辑。`task_two_resume/summary.json` 如实保留 `passed=false`、`completed=true`。

## 限制与部署状态

- 以上是真实Kev推理配合理想化运动仿真，推理期间世界暂停；不是现场艇体动力学验证。
- 转向仍采用配置的角速度上限（本轮45度/秒），未引入角加速度、速度相关转向曲线、侧滑或舵机迟滞。已提供的实艇转向资料仍待进一步标定。
- 本版仅做静态预测。目标被报为运动后会退出静态记忆，动态轨迹预测和动态避让待后续处理。
- 协议无目标删除消息。仿真清场后要清理历史态势，当前通过重启报文进程实现；不能把静态目标停止发送等同于现实物体消失。
- 定位参考点暂按艇体中心处理，额外安全余量默认为0；80米禁入半径与艇体包络另行叠加。
- 没有重启或修改现有现场运行进程，也没有向现场控制端口发送测试指令。代码在服务下次启动后生效。
- 新增到达前位置检查由后续的运行时回归覆盖；`kev_policy.final.py`、`control_runtime.final.py` 是最终保护逻辑快照。闭环期间模型请求与路径逻辑没有变化。

## 复现及文件

```bash
.venv/bin/python -m unittest discover -s server/tests
.venv/bin/python server/experiments/field_tasks.py --task both --steps 6000 --static-situation server/experiments/tasks/static_situation.json --output server/experiments/results/static-field-tasks
```

- `task_one/`：原始任务、目标样本、逐步真实模型请求响应、完整轨迹、速度与航向、汇总。
- `task_two/`：超时停车前第一段的完整记录，不覆盖失败结果。
- `task_two_resume/`：原停车位置续测的独立记录和初始完成航点数量。
- `occupied_waypoint_probe/`：原任务一第4航点被占据的局部探针，原到达半径100米。
- `static-avoidance-detail.png`：任务一绕障以及航点中心被占据的局部轨迹。
- `replay-audit.json`：18,933条原始报文回放汇总。
- `*.py`：相关实现快照、续测和绘图脚本。
